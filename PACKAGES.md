# Пакеты

Каталог пакетов панели — **только через [apkg](https://github.com/initialfox/yandex-station-repo)**.

- Индекс: `https://raw.githubusercontent.com/initialfox/yandex-station-repo/main/packages.json`
- Бинарники: ветка `pkg` того же репо
- В UI «Пакеты» панель дергает `apkg update` / `apkg install`
- Если `apkg` нет на колонке — панель скачивает его сама

Локальный `repo/packages/` в релизе панели больше не поставляется.
