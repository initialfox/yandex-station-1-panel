[SIZE=4][B]eQuasar — включение ADB на Яндекс.Станции[/B][/SIZE]
[SIZE=2]через утечку ключей Emudhra · архив [B]eQuasar-trunk.zip[/B] во вложении[/SIZE]

[QUOTE]MITM с сертами Emudhra. Работает, пока Яндекс не отозвал сертификаты. На свой страх и риск.[/QUOTE]

[B]Нужно:[/B]
[LIST]
[*] nginx
[*] DNS-сервер
[*] роутер с кастомным DNS по DHCP
[*] архив eQuasar-trunk.zip
[/LIST]

[B]Проверено:[/B] [CODE]yandexstation_mini2 0.369.1.46.4778262943.20261013.299[/CODE]

credits: [URL=https://blahaj.digital]bitracker[/URL]

[SPOILER=Содержимое архива]
[CODE]
equasar/
  README.md
  copymetoroot/
    etc/nginx/sites-enabled/quasar
    opt/fakequasar/certs/fullchain.pem
    opt/fakequasar/certs/quasar-all.key
[/CODE]
[/SPOILER]

[SPOILER=Установка nginx]
[CODE]
cp -a equasar/copymetoroot/. /
nginx -t && systemctl reload nginx
[/CODE]
[/SPOILER]

[SPOILER=DNS]
[B]На nginx:[/B]
[CODE]
quasar.yandex.net
quasar.yandex.ru
scbh.yandex.net
[/CODE]

[B]На 127.0.0.1 / мёртвый IP:[/B]
[CODE]
strm.yandex.ru
rpc.alice.yandex.net
uniproxy.alice.yandex.net
alice.yandex.net
alice-ats.yandex.net
alice-ats-test.yandex.net
[/CODE]
[/SPOILER]

[SPOILER=Активация]
[LIST=1]
[*] Отдать станции DNS по DHCP
[*] Перезапустить станцию
[*] Перезапустить ещё раз
[*] [CODE]adb connect <IP>:5555[/CODE]
[/LIST]
[/SPOILER]

[/LIST]
